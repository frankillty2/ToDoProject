# ToDoProject
Невеликий навчальний проєкт для роботи зі списком завдань.

## Можливості
- додавання завдань;
- перегляд завдань;
- видалення завдань;
- пошук завдань.

## Структура проєкту
- `src` — програмний код;
- `tests` — тести;
- `docs` — документація;
- `.gitignore` — список файлів, які не відстежуються Git.
